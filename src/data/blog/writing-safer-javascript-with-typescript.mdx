## What is TypeScript?

TypeScript is just types with JavaScript.

JS is loosely typed language so, TypeScript allows specifying the types of data being passed around within the code.

TypeScript is a superset of JavaScript.

The code you write in TS gets converted to JS. ‘cause the browser only understands JS.

TS is type checker, because of type checker we get consistency in code.

TypeScript = JavaScript + **static typing**
