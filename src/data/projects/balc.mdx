# BALC: Comprehensive CAD & IT Training Institute.

## Overview

BALC is a modern, production-ready developer portfolio and blog built using Next.js. It combines a clean, minimal UI with a scalable content system powered by MDX, allowing projects and blogs to be managed as code. The platform uses dynamic routing for flexible content rendering, focuses on performance and SEO best practices, and is designed to grow over time without becoming hard to maintain.

## What Users Can Do

- **Browse Events**: Discover upcoming college festivals, hackathons, and events
- **Event Registration**: Register for events with real-time availability tracking
- **Profile Management**: Create and manage user profiles with event history
- **Real-time Notifications**: Receive instant updates about event changes and announcements
- **Event Details**: Access comprehensive event information including schedules, venues, and requirements
- **Registration Status**: Track registration status and receive confirmation updates
- **Event Timeline**: View chronological timeline of upcoming and past events
- **Search & Filter**: Find events by categories, dates, and popularity


## Why we Built This

We built BALC Website to solve the common problems faced by students while joing a Computer Institute:

- Build a strong digital presence in Bangalore
- Help students discover nearby computer centers easily
- Make local institutes visible online
- Improve access to quality computer education
- Reduce confusion between good and low-quality institutes
- Provide clear information about courses and skills
- Support students from non-tech backgrounds
- Create trust through a professional online platform
